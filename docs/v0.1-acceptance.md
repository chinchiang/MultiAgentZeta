# v0.1 必做條文驗收對照表

本表依規格 v1.4.48 的 139 條必做要求整理。每列連回原條文及其驗收方式。程式欄列出明確引用條文的模組，案例欄列出一個可追查的相關測試。「待定位」及「待對應」表示本次尚未建立連結，仍可能有實作或案例。

表中既有案例的驗證版本為 `2587231`。案例通過只涵蓋該案例實際檢查的行為；整條驗收仍須依規格所列的正反情境、實際環境及輸出逐項確認。對照表涵蓋全部條文，未以測試數換算產品完成率。

## 驗證證據

控制區跨行程競爭、取代失敗後重試及原版本讀回見 [控制區測試](../toolkit/tests/test_control.py)。額外核准的姓名取自測試授權紀錄；人工覆核的決定者取自平台帳號，再比對角色。兩條路徑分別由[報告測試](../toolkit/tests/test_report.py)與[覆核測試](../toolkit/tests/test_review.py)驗證。報告的額外核准姓名標示在修正前未通過新增斷言，修正後通過。

本次工具包測試 419 項、文件工具測試 94 項均通過，規格產物檢查也通過。未執行實際 Supabase 服務的整合測試。控制區鎖套用在目錄層級，同一目錄內的工具包寫入會依序進行。

在專案根目錄執行下列指令即可重跑本次驗證。工具包測試使用專案虛擬環境；掃描測試只選取確認清單案例。

```bash
set -e
for suite in control confirmation authorization review report model_review inventory extract policy coverage item_rule github; do
  .venv/bin/python -I -m unittest discover -s toolkit/tests -t . -p "test_${suite}.py"
done
.venv/bin/python -I -m unittest discover -s toolkit/tests -t . -p test_scan.py -k ConfirmationListInScan
python3 -I -m unittest discover -s docs/toolkit/tools
python3 -I docs/toolkit/tools/build.py --check
```
